# Flask and MongoDB Assignment

GitHub repository: https://github.com/aaghadge09/Flask_MongoDB_aryan

## Project files

- `app.py` — Flask application and routes.
- `data.json` — data returned by `/api`.
- `templates/` — frontend pages.
- `requirements.txt` — Python dependencies.

## Run locally

Install dependencies with `pip install -r requirements.txt`, configure `MONGODB_URI` in your environment, then run `python app.py`.

The To-Do form submits to `/submittodoitem`. Keep MongoDB credentials private; do not commit them to this repository.
